# 单载体信息组件 · 动效范式

适用于"一次只展示一件事"的浮层组件：状态提示条、通知条、悬浮面板、升级版 Toast。
不适用于多条目列表、表单、需要长时间停留的常驻界面。

配套 `art-style/SKILL.md`（静态视觉语言）。本文件只管**动效与形态**，色值两者共用。

## 一、五条铁律

1. **一个载体承载全部。** 整块界面就是**一个**容器，所有内容直接排布其上。禁止在容器内再套卡片、再分小面板。分区感只能靠**排版**（间距、对齐、留白）与**透明度**。
2. **配色克制到近乎单色。** 底色低饱和深色，文字纯白，**唯一彩色只有一个**且只表达状态。不用渐变、阴影、多层半透明叠加。
3. **文字纯色，层级靠不透明度与字号反差。** 白 100% / 55% / 40% 三档足够；字号要有大反差，不要 14/15/16 挤在一起。
4. **运动传递结构。** 形态变化本身就是信息：圆 → 方 = 从"符号提示"切到"数据展示"；变**高度**而非宽度，**横向长度全程恒定**。
5. **图标几何化、单色、零 emoji。** 由 2–3 个基础几何在半标准网格上拼出，风格统一。

## 二、载体形态与定位

**形态**

| 参数 | 规则 |
|---|---|
| 长度 | **全程恒定**，动画不改长度 |
| 高度 | 收起态 `60` → 展开态 `90` |
| 圆角 | 收起 `30`（= 高/2，全圆端）；展开 `18`（≈ 高/5）。**圆角与高度反相关** |
| 整体缩放 | `0.8`，拖在最外层容器，内部按未缩放基准设计 |

只动高度与圆角，绝不动宽度——宽度一变，整套排版与位移动画全崩。中间态线性插值。

**裁剪即装饰。** 容器设 `overflow:hidden` + 圆角，内部装饰（扩散环、扫光、粒子）**故意超出边界被切掉**——画得很大，只露容器内的一小段弧。这是工业感最省成本的一招。

**定位（浮层专用）**

- **强制主显示器**，绝不"跟随窗口上次所在屏"——一旦落到副屏就再也回不来。
- 用**窗口自身**的缩放换算物理宽度，不要用屏幕的缩放（跨屏或 DPI 变化后会失真，表现为"每次触发都偏一点"）。
- 定位在显示**前、后、下一帧**各做一次；多屏环境再加一次"是否真在主屏"的自检。
- **不改写窗口宽度**，只算居中偏移。

## 三、色彩与文字

| 角色 | 值 | 用途 |
|---|---|---|
| 载体底 | `#312F30` | 实心填充，无渐变 |
| 深色底盘 | `#262425` | 比载体更深一档，用于圆形底盘 |
| 浅色底板 | `#E9E7E4` | 深底上的浅色圆/方块 |
| 板上墨色 | `#141313` | 浅底板上的图形 |
| 装饰 | `#656363` | 扩散环，比载体亮一档 |
| **强调色** | `#C6CA4C` | 唯一彩色，只给状态 |
| 告警色 | `#FF4D4F` | 替换强调色，不同时出现 |

- 强调色**面积 ≤ 5%**，只出现在状态标识、进度弧、状态点上。大面积刷即变成儿童 UI。
- 文字只用纯白，靠 `opacity` 分三档：**1.0**（数值/标题）· **0.55**（单位、次级值）· **0.40**（英文角标）。
- **换色必须整组替换**（环、内图标、装饰件一起换）。只换一半会出现廉价的"半红半绿"。

**字号阶梯**

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 主数值 | `26` | SemiBold | 主值 |
| 次数值 | `22` | SemiBold | 次级值 |
| 单位 | `14` / `13` | Medium | 单位符号 |
| 英文角标 | `9` | Medium + 字距 `2` | `/// XXX MODE` |
| 大标题 | `26` | Bold + 字距 `2` | 中文标题 |

- 字体族：无衬线 + **CJK 回退链**，无描边，默认抗锯齿即可。
- 数值开**等宽数字**，避免变化时宽度抖动。
- 数值与单位**基线对齐**，不要垂直居中——居中会让单位浮起来。
- 小字号配大字距，大字号配小字距或 0。中文标题 Bold、英文角标 Medium，形成"中重英轻"。

## 四、图标

- 统一 **24×24** 网格，单色，可随前景色换色。
- **线性 / 实心二选一，同组必须统一。** 混用是最常见的廉价来源。
- 禁用 emoji 与系统图标资源——视觉重量与网格都对不上。
- **复杂物体抽象成"描边框 + 填充条"两个几何**，不画键盘、转轴、接口这类写实细节；左右严格对称，不对称一眼被看穿。
- 由两个错位四边形拼接的图形，**下半底边要比顶边宽**——视觉重心下沉才"稳"；上下等宽会显得飘。

## 五、运动系统

### 5.1 归一化时间线 —— 多轨道同步的唯一解法

**不要给每个元素单独写 duration + delay。** 定义**一条总时长**，所有轨道用 `0.0–1.0` 的归一化 cue 描述各自关键帧，共享同一个时钟。

```csharp
public static readonly TimeSpan Timeline = TimeSpan.FromSeconds(6.0);

// 命名时间片常量——所有轨道引用同一组常量，改一个点整条线跟着变
private const double TStart    = 0.04;   // 主体开始弹出
private const double TAppear   = 0.07;   // 载体开始出现
private const double TPillOut  = 0.09;   // 载体弹出完成
private const double TIconPop  = 0.10;   // 图标弹出到位
private const double TExpand   = 0.12;   // 撑高完成
private const double TMove     = 0.20;   // 图标滑到左侧
private const double TTitle    = 0.25;   // 说明文案淡入完成
private const double THoldB    = 0.30;   // 说明态结束
private const double TContract = 0.36;   // 收回完成
private const double THoldC    = 0.86;   // 数据态停留结束
private const double TClose    = 0.89;   // 整体收起
```

好处：改总时长只改一个数；任意两轨道的同步关系是**显式**的（引用同一常量），不靠心算 delay。

### 5.2 时间预算

| 阶段 | 占比 | 原则 |
|---|---|---|
| 出现（弹出 / 展开） | 前 **12%** | 快。用户已被动触发，不需要仪式感 |
| 说明态 | 12% – 30% | 中。够看清"是什么"就走 |
| **数据态停留** | 30% – 86%（**≈56%**） | 慢。**信息才是主角**，停留必须是全段主体 |
| 收起 | 末 **3%** | 极快，ease-in 干净离场 |

一句话：**出现要快，信息要久，消失要干脆。**

### 5.3 缓动决策表（控制点可跨平台复用）

| 用途 | 控制点 | 观感 |
|---|---|---|
| **位移** | `(0.65, 0, 0.35, 1)` | 两端慢中间快，不过冲 |
| **出现** | `(0, 0, 0.58, 1)` | 起步快、末尾稳 |
| **消失** | `(0.42, 0, 1, 1)` | 起步慢、末尾快 |
| **弹入** | `(0.175, 0.885, 0.32, 1.275)` | 轻微过冲，只用**缩放**，绝不用于位移 |
| 通用进出 | `(0.42, 0, 0.58, 1)` | 保守选择 |

**铁律：位移绝不用回弹曲线。** 回弹 80% 的行程在前 20% 时间内跑完，位移会变成"瞬移"；过冲还会让元素跳出容器边界。

### 5.4 关键帧 cue 必须严格递增

```
❌ KF(0.115) → KF(0.07) → KF(0.12)   // 乱序不报错，但会把某段压成 30ms
✅ KF(0.00) → KF(0.04) → KF(0.10) → KF(0.12) → KF(0.20) → ...
```

乱序在多数引擎里**不报错**，只是静默地把动画段压缩或倒挂——表现为"某个动作突然瞬移"。写完时间线**第一件事**就是核对 cue 单调递增。

### 5.5 形态切换用交叉淡化

图标从圆切到方：两条透明度轨道**反向交叉**（`CircleForm 1→0` 与 `SquareForm 0→1` 在同一时间片内），而不是在同一帧硬换元素。

### 5.6 内容延迟显现

**容器没完全弹出，内容不许出现。** 提前显示会读作"两个东西在打架"。

```
载体弹出完成 cue = 0.05
内容淡入        cue = 0.05 → 0.08   （等容器就位再快速显现）
```

### 5.7 装饰服从内容

- 装饰的**源点必须锚在主体上，并跟随主体位移**——主体滑动时装饰必须同曲线、同时间片，否则会脱开。
- 扩散从 `scale 0` 起，起点可带垂直偏移（如从主体正下方 16px 起），扩散过程中抬升到同心——比原地放大有生命感。
- 内圈做**实心圆**而非环，外圈才是细环，层次最清晰。

### 5.8 中断与复位

任何时候可被下一次触发打断：取消令牌 → 复位全部属性到初始值 → 重跑。
**复位必须完整**（变换、透明度、尺寸、裁剪尺寸），否则第二次播放会带着上次残留（表现为"位置越来越偏"）。

### 5.9 平台映射

| 概念 | C# / XAML | Web (CSS/WAAPI) | Flutter |
|---|---|---|---|
| 缓动 | `KeySpline(x1,y1,x2,y2)` | `cubic-bezier(x1,y1,x2,y2)` | `Cubic(x1,y1,x2,y2)` |
| 归一化时间线 | `Animation{Duration} + KeyFrame{Cue}` | `@keyframes{offset}` + `duration` | `AnimationController` + `Interval` |
| 变换组 | `TransformGroup` | `transform: scale() translate()` | `Transform.scale/translate` |
| 裁剪 | `ClipToBounds + CornerRadius` | `overflow:hidden + border-radius` | `ClipRRect` |
| 几何图标 | `StreamGeometry` + `PathIcon` | `<svg><path>` | `CustomPainter` / `Icon` |
| 进度弧 | `ArcSegment` | `stroke-dasharray/dashoffset` | `CustomPainter` |
| 文字分层 | `Opacity` | `opacity` / `color-mix` | `Opacity` |

## 六、信息三态

不是"弹个提示"，而是一个**小型叙事**：

| 态 | 内容 | 形态 | 作用 |
|---|---|---|---|
| **符号态** | 只有图标居中 | 矮容器，全圆端 | 0.3 秒抓住注意力："是什么类型的事件" |
| **说明态** | 图标左移 + 标题 + 英文角标 + 装饰 | 撑高，圆角变矩形 | "解释这件事"——标题是唯一主角 |
| **数据态** | 图标变方块贴左 + 数值 + 单位 + 状态标识 | 收回，全圆端 | "给具体数据"——停留最久 |

- **图标位移**把三态串起来（居中 → 左 18% → 贴左内边距），视线跟着图标走，实现"无需阅读的引导"。
- 说明态的装饰（扩散、大标题）在进入数据态时**随标题一起淡出**，不留残余。
- 数据态用**等宽三栏**：图标 + 数值靠左 / 中间留空 / 百分比 + 标识靠右。中间留白是刻意的，把"量"和"状态"分成两组。
- **简化版**：不需要说明的场景直接省掉说明态——弹出 → 数据态 → 收回，总时长压到 5s。

## 七、反模式

| ❌ | ✅ |
|---|---|
| 容器里再套卡片分区 | 元素直接排在容器上，靠留白分区 |
| 宽度也跟着动画变 | 宽度恒定，只动高度与圆角 |
| 位移用回弹曲线 | 位移用 `(0.65,0,0.35,1)`，回弹只给缩放 |
| 关键帧 cue 乱序 | 严格递增，写完先核对 |
| 每个元素各写各的 delay | 一条归一化时间线 + 共享常量 |
| 大标题和数值一样大 | `26 / 22 / 13 / 9` 的大反差阶梯 |
| 用灰色文字做次级 | 纯白 + 不透明度 1.0/0.55/0.40 |
| 状态变化只换一个环的颜色 | 整组（环 + 图标 + 装饰件）同步换色 |
| 大面积刷强调色 | 强调色 ≤5%，只表达状态 |
| 内容在容器弹出前就显示 | 容器就位后再淡入 |
| 画写实的复杂图标 | 抽象成描边框 + 填充条 |
| 加阴影和渐变增加"层次" | 层次靠不透明度与面积 |
| 浮层跟随上次落点 | 强制主屏 + 每次重算 + 显示前后各定一次 |
| 窗口宽度被反复改写 | 宽度固定，只算居中偏移 |

## 八、验证

1. **静帧**：把动画暂停在三个态各截一图——每一帧单独看都应是完整好看的静态构图，而不是只有动起来才成立。
2. **降速**：0.25× 播放一遍。"瞬移""硬切""提前显示"在慢放下无处遁形。
3. **循环**：连续触发 **5 次以上**。位移漂移、状态残留、装饰脱开这类 bug 只在第 2 次之后暴露。
4. **单色**：截图去色。灰度图看不出信息层级 → 说明配色在掩盖排版问题。
5. **面积**：高亮强调色区域，超过 5% 就砍。
6. **尺寸**：在最窄目标尺寸下验证不溢出、文字不换行。
