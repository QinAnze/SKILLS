# 科研级数据绘图

**决策优先级**：统计语义 > 数据完整性 > 信息编码 > 可读性 > 版式 > 美观。
**推进顺序**：数据 → 问题 → 统计单位 → 变量类型 → 视觉编码 → 不确定性 → 可访问性 → 版式 → 导出。

> 顺序反了只会得到"漂亮但结论站不住"的图。**图是论点，不是数据的照片。**
> 统计语义排第一——**绘图不等于统计推断**，混在一起是这类任务最致命的错误。

## 一、执行协议（拿到数据后按此执行）

| 步 | 动作 | 产出 |
|---|---|---|
| 1 Inspect | **只读不改**。查 shape / columns / dtype / 缺失 / 重复行 / 取值范围 / 分组结构 / **重复层级** | 数据画像 |
| 2 Clarify | 判断绘图目的；存在多种合理解释时**先问用户**，不猜 | 一句话论点 |
| 3 Statistical representation | 定观察单位、n/N、汇总统计量、不确定性类型、是否做检验 | 统计表征方案 |
| 4 Plot | 显式给定 figsize / dpi / font / 颜色(hex) / linewidth / markersize，不依赖默认 | 图 |
| 5 Validate | 程序化 + 人工双重检查（§八） | QA 通过 |
| 6 Export | 矢量优先 + 栅格备份 + 可复现代码（含参数与随机种子） | 交付 |

**第 2 步是分水岭**：用户说"画个散点图"，可能是看相关性、看分组差异、还是找离群点——三种目的三种画法（加回归线 / 按组着色 / 加标注）。问一句，省三轮返工。

## 二、铁律

1. **目的一句话**：说不出这张图在说什么，就是图型选错了。
2. **先看数据再动手**：结构、量级、分布、缺失、**重复层级**——决定能画什么。
3. **三件套必标**：变量名 + 单位 + n；**n 必须说明统计单位**（§3.1）。
4. **不确定性必须画**，并注明是**哪一种**（SD / SEM / CI / IQR…），语义见 §3.2。
5. **尺度与变量性质匹配**：柱状图必须从 0；点图/折线不要求从 0；log2FC 的 0 是生物学中心。非零起点、断轴、特殊尺度须在图注说明，且不得造成视觉误导。
6. **数据不许动**：不得为"让图更好看"删离群点、改数据、静默变换、跑检验、加显著性标记（§3.3–3.5）。
7. **颜色写具体色号**，色盲友好优先；**颜色不承担唯一信息**（同时用形状/线型/填充区分）。
8. **一图一峰**：信息多了分面或多面板，不往一张图上堆。
9. **出版级默认**：矢量优先、位图 ≥300 DPI（线图 600）；尺寸按目标期刊栏宽。**期刊 author guidelines 优先于本 skill 的任何默认值。**
10. **导出后回看**：标签未裁、图例未出界、字号可读、**灰度下仍可辨**。不回看不算完成。

## 三、统计语义层（AI 最常出错的地方）

### 3.1 重复层级 —— n 到底是什么

```
n 必须说明统计单位，不同单位的 n 不可混用：
  biological replicates  独立生物学样本（小鼠 / 患者 / 批次 / 个体）
  technical replicates   同一样本重复测量 —— 默认不视为独立样本
  observational unit     统计推断的最小独立单位

nested / repeated measures：标明层级；技术重复不得当独立 n；必要时用混合效应模型。
```

**典型陷阱**：数据里 `n = 96`，实际是 `3 biological × 32 technical`——统计意义完全不同。遇到生医/生工数据先问这一句。

### 3.2 不确定性的语义（选错 = 结论错）

| 量 | 表达什么 | 何时用 |
|---|---|---|
| SD | **观测值**的离散程度 | 想展示个体差异 |
| SEM | **均值估计**的标准误；**不表示个体分布** | 只关心均值精度且已说明 |
| 95% CI | 参数估计的不确定性 | 推断场景（推荐默认） |
| IQR / 分位数 | 分布的中间 50% / 任意分位 | 偏态数据、稳健汇总 |
| prediction / credible | 单次预测 / 后验分布 | 预测类、贝叶斯 |

**禁止**："为了让误差棒看起来更小、更稳定，改用 SEM。"——这是选择性让数据显得更干净。误差棒类型由研究问题决定，不由视觉效果决定；不确定时用 CI 或直接展示分布，并在图注写明。

### 3.3 不得擅自统计

用户只让"画一下"时，**不得自动**做 t 检验、算 p 值、加显著性星号、拟合回归、选择统计模型。若确实需要检验：必须说明**方法、假设、n、多重比较校正**，并在图注写出；显著性标记只标注**校正后**的 p 值。

### 3.4 数据变换透明

`log10 / log2 / z-score / 归一化 / 标准化 / 基线扣除 / fold change / 百分比变化`——**任何变换都必须显式说明**，不得为"让图更好看"静默变换。三层须在代码与图注中可分辨：

```
原始值 → transformation → plotting scale
```

**轴是 log 刻度 ≠ 数据做过 log 变换。**

### 3.5 离群值

**Outlier ≠ error。** 默认**保留、显示、不删除**。只有存在明确的数据质量依据（记录在案）才可排除，并写明排除标准与数量。离群点优先"标注"而非"隐藏"。

## 四、图型决策

### 4.1 按分析目的

| 目的 | 首选 | 注意 |
|---|---|---|
| 连续变量比较（原始观测值重要） | **点图 / strip / beeswarm + 汇总** | 默认首选；n 小时直接显示每个点 |
| 两组或少数组比较 | **point plot / estimation plot** | 直接显示效应量与 CI |
| 分布比较 | 箱线图、小提琴图 | 小提琴须叠内部结构；n 小时 KDE 失真 |
| 均值 + 不确定性本身是重点 | 点 + 误差棒 / CI | 注明误差棒类型 |
| **比例 / 计数** | **柱状图** | **仅此场景用柱**；必须从 0 |
| 分布 | 直方图、密度图 | 偏态加 log 轴；多组用半透明或 ridge |
| 关系 | 散点图、回归图 | 加拟合线 + 置信带；大样本转六边形分箱 |
| 时间 | 折线图 | 多序列分面优于堆叠；标出实际观测点 |
| 高维 | PCA、UMAP、聚类热图 | 见 §4.3；参数必须记录 |
| 推断 | 置信区间图、森林图、系数图 | 注明检验方法、效应量、校正 |
| 相关结构 | 相关热图（发散色，中点居中） | 按聚类重排；加数值或显著性 |
| 比例变化 | 斜率图 slope chart | 优于两组柱对比 |
| 排序 / 重要性 | 横向条形图 / lollipop | 按数值排序，不按字母序 |

> **柱状图不是 comparison 的默认选项**——它同时隐藏样本量、分布形状与离群值。只有画**比例/计数**、或"均值+CI 本身就是主角"时，柱状图才成立。
> **反向检查**：换成另一个图型，结论会变吗？会变说明图型在替数据说话。

### 4.2 领域招牌图型

- **生物 / 医学 / 组学**：火山图（log2FC vs -log10 padj；画阈值线、标注 top）｜MA 图｜PCA/UMAP｜聚类热图｜富集气泡图（点大小=计数、点色=-log10 FDR）｜KM 生存曲线（风险人数表 + 删失标记 + HR 与 CI）｜单细胞 dot plot（点大小=表达比例、点色=平均表达）｜>3 集合用 UpSet
- **化学**：光谱图（峰位与归属标注）｜结构-性质回归（R² 与 n）｜响应面 / 等高线
- **物理 / 工程**：拟合曲线（参数、误差、R² + 残差子图）｜相图（明确物理量与温标）｜频谱 / PSD（说明窗函数与分辨率）
- **金融 / 经济**：时序 + 回撤子图｜收益分布（叠核密度与正态参考）｜相关热图｜分位数分组柱图。**颜色约定：涨红跌绿（中国默认）；货币符号 ¥**
- **社会科学**：箱线/小提琴 + 显著性｜forest plot / 系数图（误差棒=CI）｜Likert 用居中发散堆叠条

### 4.3 生信 / 高维图常见误用

| 图 | 误用 |
|---|---|
| 火山图 | 用 p 代替 padj；不报 log2FC 阈值；不提多重检验校正 |
| 热图 | 原始值当标准化值；不说明行/列 z-score 方向；不报 distance + linkage |
| PCA | 不报 PC1/PC2 方差解释率；不提 scaling / centering；忽略批次效应 |
| UMAP / t-SNE | 当作统计推断（**visualization ≠ inference**）；不报 n_neighbors / min_dist / metric / random_state |
| dot plot | 混淆点大小（表达比例）与点色（表达量）的语义 |
| 生存曲线 | 缺删失标记、风险表、中位生存时间、HR + CI |

**可复现性**：所有降维 / 聚类必须记录参数与随机种子。

## 五、视觉编码与配色

### 5.1 配色决策树（要决策系统，不要颜色清单）

```
数据编码类型？
├─ categorical 定性
│   ├─ ≤ 8 类 → Okabe-Ito（含纯黑，色盲友好最稳）
│   └─ > 8 类 → 不要继续加颜色：改连续色阶 / 分面 / 高亮少数 + 其余灰
├─ sequential 连续 / 有序
│   ├─ 通用 → viridis（感知均匀）
│   ├─ 可访问性关键（红绿色盲、灰度打印）→ cividis
│   └─ 单色系（如表达量深浅）→ 同色相明度梯度
└─ diverging 双向偏离
    ├─ 有明确中点（0 / 基线 / 中性值）→ RdBu、BrBG
    └─ 无明确中点 → 不要用 diverging，改用 sequential
```

**发散色图铁律**：中点（0 / log2FC=0 / 无相关）**必须落在色阶中心**，色标取 `vmin = -A`、`vmax = +A`（A = 最大绝对值）保持对称，否则正负会被视觉抹平。**不用彩虹色阶做连续映射**（感知不均匀，会造出虚假边界）。

### 5.2 常用色号（hex，直接用）


**写色号，不写配色名**——名称在不同库/版本对应色值会变，hex 不会。同一含义全篇同一色号；颜色顺序跟着数据的逻辑顺序（时间序 / 剂量序 / 分组层级），图例顺序一致。

### 5.3 可访问性检查（色盲友好 ≠ 灰度可辨）

```
□ 色盲模拟（deuteranopia / protanopia）
□ 灰度转换：组间是否仍可区分（浅蓝 vs 浅紫 vs 浅绿 通常全糊）
□ 低分辨率 / 缩略图：缩到 30% 还读得出吗
□ 投影 / 打印：一页多图时颜色是否互相干扰
```

**颜色不是唯一编码**：关键组别同时用**形状 / 线型 / 填充纹理 / 直接标注**区分。有语义约定的场景（涨跌、冷热、正负）优先于色盲偏好——但须同时保证形状或线型可辨。

## 六、版式与标注

- **尺寸**：单栏 ≈ 89 mm｜1.5 栏 ≈ 114 mm｜双栏 ≈ 183 mm
- **必存**：`变量名 (单位)` 轴标签｜图例不遮数据｜n（含统计单位）｜统计信息（方法/阈值/校正）｜多面板编号 `(a)(b)(c)` 放左上角、全组一致
- **该删**：图内标题（由图注承担）｜网格线（保留则极淡）｜上右边框｜背景色、渐变、阴影、3D、emoji 标记
- **一致**：统一无衬线字体，不混衬线｜最小字号 ≈7 pt、正文级 8–10 pt、标题 11–12 pt｜轴线 0.5–0.8 pt、数据线 1.0–1.5 pt
- **中文**：显式指定中文字体（SimHei / Microsoft YaHei / Noto Sans CJK SC）并设 `axes.unicode_minus=False`；矢量导出嵌入字体或转曲。能英文标注就英文。

## 七、导出

```
默认：矢量优先（线条/图形用 PDF/SVG）；需要位图时 ≥300 DPI（线图 600）。
期刊 author guidelines 与本默认冲突 → 以期刊要求为准。
line art / halftone / combination artwork 三类要求可能不同，按刊逐项核对。
```

| 格式 | 用途 | 要点 |
|---|---|---|
| PDF | 投稿首选矢量 | 字体嵌入（`pdf.fonttype=42`） |
| SVG | 网页 / 可编辑 | 文字保持可编辑（`svg.fonttype='none'`） |
| PNG | 汇报、位图投稿 | 300–600 DPI，非透明背景 |
| TIFF | 部分期刊要求 | 300–600 DPI，LZW 压缩，必要时 CMYK |

```python
fig.savefig(OUT, dpi=300, bbox_inches="tight", facecolor="white")   # PNG
fig.savefig(OUT, format="pdf")                                      # 矢量
# R: ggsave(OUT, p, width=89, height=66, units="mm", dpi=300)
```

尺寸用英寸 / 毫米**显式给定**，不依赖默认画布；无界面环境用无头后端。

## 八、出图 QA

**程序化（代码里做）**：NaN / Inf 检查｜轴范围与刻度｜图例存在且未越界｜文本未被裁切｜字体实际生效｜色号与既有定义一致｜画布尺寸与目标一致。

**人工（回看）**：

- [ ] 一句话能说清这张图在说什么？
- [ ] 变量名 + 单位 + n（含**统计单位**）齐全？
- [ ] 误差棒的**类型**写了吗？是否被"看起来更好"绑架过？
- [ ] 有没有擅自做检验、加星号、删点、静默变换？（有 → 撤回）
- [ ] 尺度：柱状图从 0？log 轴已标注？非零起点已说明？
- [ ] 配色走的是决策树吗？类别 ≤8？中点居中？灰度下可辨？
- [ ] 图例颜色与图形对应？图例挡住数据了吗？
- [ ] 降维 / 聚类参数与随机种子记录了吗？
- [ ] 中文正常显示？导出后无裁切、尺寸符合目标栏宽？

## 九、症状 → 修法

| 症状 | 修法 |
|---|---|
| 中文变方块 | 指定中文字体；`axes.unicode_minus=False` |
| 导出是空白图 | `savefig` 在绘图之后且路径正确；无界面环境用无头后端 |
| 标签 / 图例被裁 | `bbox_inches='tight'`；图例 `bbox_to_anchor` 定位 |
| 柱状图从非零起 | y 轴 `bottom=0` |
| 热图色标不居中 | `vmin=-A, vmax=+A`（A = 最大绝对值），配发散色阶 |
| 对数轴 `-inf` | 含 0 / 负值：过滤或加常数，**并在图注说明处理方式** |
| 长尾分布看不出结构 | 换 log 轴，或线性 + log 双面板并列 |
| 散点糊成一坨 | 降 alpha、缩小点、六边形分箱、抽样 |
| 类目标签重叠 | 旋转 30–45°、换行、缩写，或改横向条形图 |
| 图例颜色与图形不符 | 被库的默认调色板覆盖——改回显式 hex |
| 双轴造出伪相关 | 拆成上下两个子图，共享 x 轴 |
| 均值柱看不出分布 | 叠散点或改点图——柱状图在隐藏信息 |
