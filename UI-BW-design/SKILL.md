# 极简黑白 UI 设计风格手册

> 一套适用于桌面应用的极简黑白 UI 设计风格指南——零圆角、受限配色、功能优先、边框即装饰。

---

## 一、设计哲学

**「零圆角 · 受限配色 · 功能优先 · 边框即装饰」**

用极少的元素、克制的色彩、硬朗的几何来构建界面。粗黑边（2px）强调功能分区、细黑边（1px）营造精致感、无边框+分隔线将极简推到极致。三种策略本质上是同一套语言。

核心逻辑是：**去掉一切不必要的装饰，让内容和工作流本身成为界面主角。** 圆角去掉、阴影去掉、渐变色去掉——只留下形状、边框、文字和空间。

---

## 二、色彩体系

### 2.1 纯黑白基底

整个配色系统建立在黑白灰的灰度梯度上：

| 层级 | 色值 | 用途 |
|------|------|------|
| 纯白 | `#ffffff` | 页面背景、卡片、输入框 |
| 暖白 | `#fafaf9` | 页面背景（浅色主题） |
| 浅灰 | `#fafafa` / `#f5f5f4` | 次级背景、图表区 |
| 中灰 | `#f5f5f5` / `#f6f8fa` | 悬停背景、表头、行内代码背景 |
| 深灰 | `#e7e5e4` / `#e0e0e0` | 边框、分隔线、按下状态 |
| 过渡灰 | `#bbbbbb` / `#a8a29e` | 禁用文字、三级文字 |
| 次黑 | `#78716c` | 次级文字、图标 |
| 深灰黑 | `#555555` / `#1c1917` | 主文字（暖调） |
| 纯黑 | `#000000` | 边框、主文字（冷调）、强调 |

### 2.2 双主题系统

在黑白基底之上，可扩展出一套双主题方案：

**浅色主题（默认）：** 暖白中性调
- 背景 `#fafaf9`、卡片 `#ffffff`、悬停 `#f5f5f4`
- 文字 `#1c1917`（暖黑），次级 `#78716c`，三级 `#a8a29e`
- 分隔线 `#e7e5e4`

**蓝色主题：** 纯蓝调
- 背景 `#2f55cb`、表面 `#365ecf`、次级 `#2a4db8`
- 文字纯白 + alpha 变体（72% / 45%）
- 分隔线 `rgba(255,255,255,0.12)`

主题切换通过 CSS 变量 + `html[data-theme]` 实现，所有组件跟随变量自动变色。

### 2.3 语义色彩

在严格的黑白灰之上，彩色被极度克制地用于语义高亮：

| 语义 | 色值 | 场景 |
|------|------|------|
| 行内代码前景 | `#d63384` | 编辑器内联代码 |
| 链接 | `#4183C4` | 超链接 |
| 引用文字 | `#6a737d` | 引用块 |

代码块是唯一允许出现丰富色彩的地方。可采用 **One Dark 风格**——深灰蓝底 `#282c34`，搭配柔和绿 `#98c379`、紫/品红 `#c678dd`、青 `#56b6c2`、橙 `#d19a66`、蓝 `#61afef`、黄 `#e5c07b`。在黑白界面中创造了一个视觉焦点区域，犹如黑白照片中的一抹亮色。

### 2.4 交互状态色彩

| 状态 | 处理方式 |
|------|----------|
| 悬停 | 背景变浅灰（`#f0f0f0` ~ `#f5f5f4`） |
| 按下/激活 | 背景变深灰（`#e0e0e0`） |
| 选中 | 黑底白字反转（`#000` 底 + `#fff` 字） |
| 禁用 | 灰底（`#f5f5f5`）+ 灰字（`#bbb`） |
| 选中复选框 | 黑底白框，勾选后黑填充 |

## 三、形状与边角

### 3.1 零圆角规则

**所有 UI 元素强制 `border-radius: 0px`**。这是不可打破的铁律。

零圆角的本质是表达一种现代主义设计态度：界面不应该是"友好"的、"柔和"的，而应该是精确、锐利、功能性的。按钮、输入框、下拉框、分组框、标签页、弹窗、卡片——没有任何元素可以有圆角。

唯一的例外是消息气泡场景——气泡的尾部可用 4px 的小圆角来区分发送方和接收方，其余三个角保持 12px——这已经是对"零圆角"原则最大程度的让步。

### 3.2 边框系统

零圆角之后，边框成为定义形状、区分层次、创造质感的唯一工具。有三种边框策略可选：

| 策略 | 宽度 | 色值 | 效果 |
|------|------|------|------|
| 粗边框 | 2px solid | `#000000` | 强调功能分区、工业感 |
| 细边框 | 1px solid | `#000000` | 精致、克制、复古感 |
| 无边框 + 分隔线 | 1px solid | `#e0e5e4` / `#e7e5e4` | 极简、轻盈、杂志感 |

粗边框让每个面板和控件像独立的"工业模块"一样清晰可辨。细边框则像印刷品中的装饰线，精致但不抢眼。去掉边框后，完全依赖间距和微妙的背景色差来区分元素——这是极简主义的极致形态。

## 四、字体排版

### 4.1 字体性格体系

在黑白配色中，字体选择决定了整体气质。有四种字体性格可选：

| 字体类型 | 字体栈 | 气质 |
|----------|--------|------|
| **等宽字体** | Courier New → Consolas → Menlo → Monospace | 复古、专注、终端风 |
| **无衬线（系统字体）** | SF Pro → Segoe UI → 系统默认 | 中性、现代、工具感 |
| **衬线字体** | Georgia → Noto Serif SC → Source Han Serif SC → SimSun | 优雅、编辑感、杂志感 |
| **手写体** | Edwardian Script ITC → Brush Script MT / 自定义字体 | 个性、品牌化 |

### 4.2 字号层级

| 层级 | 字号 | 用途 |
|------|------|------|
| 超小 | 9px monospace | ASCII 艺术 Logo |
| 极小 | 11px | 代码字体、时长/元数据 |
| 小 | 12-13px | 正文、次级文字、状态栏 |
| 中 | 14px | 按钮、歌曲标题、正文 |
| 大 | 16-18px | H4-H3 标题 |
| 超大 | 22-26px | H2-H1 标题 |
| 巨大 | 30px script | 手写体品牌标志 |
| 英雄 | 38px | 英雄区标题 |

### 4.3 标题层级（Markdown 编辑器场景）

H1: 26px / H2: 22px / H3: 18px / H4: 16px / H5: 14px / H6: 12px

## 五、布局模式

### 5.1 侧栏 + 主区 + 底栏（内容消费类应用布局）

适用于音乐播放器、阅读器等场景：

```
┌──────────┬─────────────────────────────────────┐
│ Sidebar  │  Main                               │
│ 240px    │  ┌──────────────────────────────┐   │
│          │  │ Topbar (搜索 + 操作)          │   │
│  ASCII   │  ├──────────────────────────────┤   │
│  Logo    │  │ View (发现/搜索/曲库)          │   │
│  ──────  │  │                              │   │
│  导航    │  └──────────────────────────────┘   │
│  歌单    ├─────────────────────────────────────┤
│  ♥ 收藏  │  Player Bar (68px)                   │
└──────────┴─────────────────────────────────────┘
```

关键特征：侧边栏固定宽度 240px、主区域自适应、播放栏固定 68px。
歌曲列表采用 CSS Grid：`40px 3fr 2fr 2fr 60px`（# 歌曲 艺人 专辑 时长）。
响应式断点 900px，小于此宽度时隐藏侧边栏、精简歌曲行。

### 5.2 多面板嵌套分割（工具类应用布局）

适用于数据可视化、IDE 等场景：

- 主窗口水平分割（左侧面板 2 : 右侧面板 3）
- 左侧面板垂直分割（对话区 3 : 数据预览区 2）
- 右侧面板垂直分割（代码视图 2 : 图表输出 2 : 收藏夹 1）
- 整体垂直分割：主区域 4 : 终端面板 1

所有分割可通过 QSplitter 实现，用户可自由拖拽调整面板比例。

### 5.3 三栏编辑器布局

适用于 Markdown 编辑器、文本编辑器等场景：

- 左侧：可停靠文件树面板（QDockWidget，可关闭/浮动）
- 中央：Markdown 编辑区（QTextEdit，核心工作区）
- 顶部：菜单栏 + 工具栏
- 底部：状态栏（行号、列号、字数、字符数）

### 5.4 通用布局原则

- 固定宽度侧栏 + 自适应主区
- 顶部操作栏 + 底部状态栏
- 内容区域最大化，周围元素克制
- 分割线替代边框，减少视觉重量

## 六、图标设计

### 6.1 实现方式

| 方式 | 技术 | 特点 |
|------|------|------|
| SVG 文件引用 | Qt 资源系统 / 桌面应用传统方式 | 适合桌面应用 |
| 内联 SVG | HTML + CSS | 灵活、可随主题变色 |

内联 SVG（24×24 viewBox）通过 `currentColor` 着色——图标颜色会跟随父元素的 `color` 属性变化，实现图标与文字颜色的一致性。

### 6.2 图标清单

**操作类：** 播放、暂停、上一首、下一首、喜欢（心形）、音量、设置、导出、清除

**导航类：** 主页、搜索、音乐库

**编辑类：** 粗体、斜体、代码、标题、表格、图片、文件、列表、引用、分割线、链接、删除线

**工具类：** 上传、运行、发送、复制、缩放（放大/缩小/适应）、终端

**媒体类：** 聊天、数据、代码、图表

## 七、动画系统

在极简黑白风格中，动画不是"装饰"而是"反馈"。

### 7.1 过渡参数

```css
--transition: .2s cubic-bezier(.25,.46,.45,.94);
```

200ms 的时长既不会让用户觉得慢，也不会快到忽略。cubic-bezier 缓动函数创造出自然的加速-减速效果。

### 7.2 入场动画

```css
/* 视图淡入：微微上浮 + 渐显 */
@keyframes fade {
  from { opacity: 0; transform: translateY(6px); }
  to   { opacity: 1; transform: translateY(0); }
}

/* 歌曲行滑入：左滑入 + 渐显 */
@keyframes slideIn {
  from { opacity: 0; transform: translateX(-6px); }
  to   { opacity: 1; transform: translateX(0); }
}

/* 卡片入场：下沉入 + 渐显 */
@keyframes cardIn {
  from { opacity: 0; transform: translateY(10px); }
  to   { opacity: 1; transform: translateY(0); }
}
```

所有入场动画的位移量都很小（6-10px），目的是在不破坏极简氛围的前提下提供空间反馈。

### 7.3 脉冲动画

```css
/* 播放中封面脉冲：轻微缩放 */
@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.05); }
}
```

1.05 倍的缩放幅度几乎不可察觉，但足够传达"正在播放"的状态。

## 八、特色视觉元素

### 8.1 ASCII 艺术

ASCII 艺术在黑白界面中天然契合——它本身就是"字符即图形"的设计哲学。可用于：
- 启动画面 ASCII 艺术字
- 侧边栏 Logo（9px monospace ASCII 艺术 + 30px script 手写体）

### 8.2 歌词词云（Canvas 动态效果）

使用 Canvas 绘制动态词云：
- 词语随机大小（18px ~ 容器尺寸的 40%）
- 随机颜色（跟随预设配色方案或专辑封面提取）
- 35% 概率竖排显示
- 碰撞检测避免重叠
- 网格回退算法确保填满

配色方案：Bridge（青+粉）、Stellar（绿+橙+深红+灰）、Hypr（品红+黄+绿）、Rdm（完全随机）、Cover（从专辑封面提取）。

### 8.3 频谱可视化

Canvas 绘制的 32 段频谱条：
- 数据来源：Web Audio API AnalyserNode
- 静默时回退到 BPM 驱动的程序模拟（128 BPM）
- 条带颜色跟随主题变量

### 8.4 对话气泡

对话面板中的气泡样式：

```css
/* 用户消息：白底黑字，右侧气泡圆角 */
background: #ffffff; color: #1a1a1a;
border: 2px solid #000000;
border-radius: 12px 12px 4px 12px;

/* AI 回复：灰底黑字，左侧气泡圆角 */
background: #f5f5f5; color: #1a1a1a;
border: 2px solid #000000;
border-radius: 12px 12px 12px 4px;
```

## 九、滚动条与响应式

### 9.1 滚动条样式

```css
::-webkit-scrollbar { width: 5px; }
::-webkit-scrollbar-track { background: transparent; }
::-webkit-scrollbar-thumb { background: var(--divider); }
::-webkit-scrollbar-thumb:hover { background: var(--text-3); }
```

5px 宽度的细滚动条，轨道透明，滑块使用分隔线颜色，悬停时变深——存在感极低但功能完整。

### 9.2 响应式断点

| 断点 | 变化 |
|------|------|
| ≤ 900px | 侧边栏隐藏、歌曲行精简为 3 列、播放栏单列化 |
| 桌面端 | 完整多面板布局 |

## 十一、注意事项

1. **零圆角不等于粗糙**：需要通过精细的边框、间距和色彩层次来体现品质感。去掉圆角后，边缘的精确对齐变得更加重要。

2. **黑白配色需要层次**：通过灰度梯度（#fff → #f5f5f5 → #e0e0e0 → #bbb → #555 → #000）创造视觉深度。没有层次感的黑白界面就是"没做完"的界面。

3. **字体是灵魂**：在黑白配色中，字体选择决定了整体气质。等宽字体=复古专注，无衬线=现代工具，衬线=优雅编辑。

4. **彩色要克制**：彩色仅用于语义高亮（代码高亮、状态指示、品牌点缀）。一个页面中彩色面积不应超过 5%。

5. **动画要精准**：过渡动画时长控制在 150-250ms，缓动函数选择 cubic-bezier 而非 linear。动画幅度要小（位移 6-10px，缩放 1.05x），点到为止。

6. **边框是设计语言**：粗边框（2px）= 工业感、细边框（1px）= 精致感、无边框 = 极简主义。选择一种，贯穿始终。

7. **间距即呼吸**：在去掉圆角和阴影之后，元素之间的间距成为区分层次的主要手段。保持一致的间距系统（4px / 8px / 12px / 16px / 24px / 32px）。
